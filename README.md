# NewsHub — Entrega 1, Escenario 3

Primera versión funcional del aplicativo web de noticias desarrollado para el módulo de Front-end.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- localStorage

## Páginas
- `index.html`: página de inicio y noticias destacadas.
- `noticias.html`: catálogo, búsqueda y filtro por categoría.
- `detalle.html`: detalle de una noticia y gestión de favoritos.
- `favoritos.html`: noticias guardadas en localStorage.
- `contacto.html`: formulario con validaciones básicas.
- `admin.html`: mini CRUD para crear y eliminar noticias.

## Ejecución
Abrir `index.html` en un navegador web. La aplicación no requiere servidor para la demostración básica.
