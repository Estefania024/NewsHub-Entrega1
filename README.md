# NewsHub — Entrega 1, Escenario 3

Primera versión funcional de la propuesta de Front-end basada en los mockups del documento.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3 (CDN)
- localStorage del navegador

## Estructura
- `index.html`: Home.
- `noticias.html`: catálogo, búsqueda y filtro.
- `detalle.html`: detalle y favoritos.
- `favoritos.html`: noticias guardadas.
- `contacto.html`: formulario y validaciones.
- `admin.html`: mini CRUD (crear/eliminar).
- `css/styles.css`: estilos.
- `js/app.js`: lógica de interacción.
- `img/`: recursos gráficos, disponible para imágenes futuras.

## Ejecución
Abrir `index.html` en un navegador moderno. Para una ejecución local recomendada, usar una extensión de servidor local como Live Server en Visual Studio Code.
